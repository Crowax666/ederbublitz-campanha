# Eder Bublitz 1020 — Site de Campanha

Landing page responsiva desenvolvida para apresentar a identidade visual, trajetória e propostas da campanha de **Eder Bublitz — Deputado Federal 1020**.

## Visualização online

[**Abrir o mockup publicado**](https://eder-bublitz-1020.fabianofmachado.chatgpt.site)

## Destaques

- experiência diferenciada para desktop e dispositivos móveis;
- identidade visual e numeração 1020 em primeiro plano;
- navegação mobile, transições e animações responsivas;
- seções de trajetória, compromissos, propostas e mobilização;
- botões demonstrativos de WhatsApp e retorno ao topo;
- fotografias e materiais oficiais da campanha.

## Tecnologias

- React
- TypeScript
- Next.js / Vinext
- CSS responsivo

## Executar localmente

```bash
npm install
npm run dev
```

> Projeto conceitual em evolução. Links e contatos presentes no mockup podem ser demonstrativos.
